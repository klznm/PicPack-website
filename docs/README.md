# PicPack Website

This repository contains the source code for the official website of **PicPack**, a minimalist packing app for Android designed to help users travel stress-free.

## 🌐 Live Site

The website is published via GitHub Pages and can be accessed here:
👉 **[https://kaluzynym.github.io/repack/](https://kaluzynym.github.io/picpack/)**

## 📂 Contents

This `docs/` folder contains the static files for the website:

*   **Landing Page (`index.html`):** Showcases the app's features, screenshots, and download links.
*   **Privacy Policy (`privacy-policy.html`):** Details how user data is handled (100% private & offline).
*   **Terms of Service (`terms.html`):** The terms and conditions for using the app.
